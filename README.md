# 📄 Post Details Module

## 👨‍💻 Developed By
Pravanjan

## 🎯 Objective
The Post Details module allows users to view complete information about a selected lost or found item. This feature helps students identify items easily and provides all relevant information required for claiming or returning an item.

## ✨ Features Implemented

- Display Item Name
- Display Item Description
- Display Item Category
- Display Item Status (Lost / Found)
- Display Item Location
- Display Item Date
- User-Friendly Item Details Screen
- Navigation from Item List to Details Page

## 🛠️ Technologies Used

- Kotlin
- Android Studio
- XML Layouts
- RecyclerView
- Intent Data Passing

## 📱 Screen Flow

```
Lost/Found Items List
          ↓
    Select Item
          ↓
   Item Details Screen
          ↓
 View Complete Information
```
