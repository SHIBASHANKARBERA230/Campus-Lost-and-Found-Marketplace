# Campus Lost & Found Marketplace

An Android-based application designed to help students and campus staff
report, search, manage, and recover lost and found items within a college campus.

## Project Goal

The goal of this project is to create a centralized digital platform for
managing lost and found items on campus instead of depending on WhatsApp
groups, notice boards, or word-of-mouth communication.

## Features

- User registration
- User login and authentication
- User profile management
- Change password
- Report lost items
- Report found items
- Search for items
- View item details
- Claim found items
- Manage claims
- Favorite items
- Notifications
- Real-time communication
- Marketplace functionality

## Authentication Module

The authentication module is responsible for managing user access to the
application.

### Authentication features

- User registration
- User login
- User logout
- Password management
- Change password
- Authentication validation
- User session management

### Authentication Screens

The Android application contains authentication-related screens such as:

- Login
- Registration
- Change Password
